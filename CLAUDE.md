## About me

I'm a mechanical engineer who is new to Python. I'm comfortable with engineering
concepts (mass and energy balances, thermodynamics, fluid mechanics, process
modeling), but not with Python syntax or programming conventions.

## How to explain code

- Always explain code step by step. Walk through it in the order it runs and say
  what each part does and why.
- Explain Python concepts the first time they come up (imports, functions,
  classes, objects, indexing, loops, dictionaries, and so on), and use plain
  language rather than jargon.
- When it helps, relate the code to the engineering idea behind it, for example
  which variable is a flowrate, which constraint is a mass balance, or what a
  solver is doing.
- Before or after a change, say what changed and why, then how to run it and
  what output to expect.
- Keep code simple and readable over clever, and add comments where the intent
  isn't obvious.
